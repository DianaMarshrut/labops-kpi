# labops-kpi — KPI: показатели для должности с весами

Капсула строит систему KPI из должности и целей компании: таблица 5–7 показателей
с весами (сумма 100%), типом метрики, целевым диапазоном, источником данных и формулой бонуса.
Работает с описанием словами, файлом Excel/Word/PDF или Google Таблицей.

**Что получаешь:**
- Таблица 5–7 KPI с весами в сумме 100%.
- Тип каждого показателя: опережающий или итоговый.
- Целевой диапазон (не одна точка) и источник данных для расчёта.
- Формула бонуса с объяснением логики.
- HTML-таблица для хранения и показа команде.

## Как поставить

### Claude Code

```
/plugin marketplace add DianaMarshrut/labops-kpi
/plugin install kpi@labopsai-kpi
```

Напиши: **«KPI»**.

### Claude (claude.ai, приложение)

1. Customize → Plugins → Add marketplace.
2. Вставь ссылку: `https://github.com/DianaMarshrut/labops-kpi`
3. Установи плагин «kpi».
4. Напиши: **«KPI»**.

### Codex

```
codex plugin marketplace add DianaMarshrut/labops-kpi
```

Через `/plugins` → Install → новая сессия → напиши: **«KPI»**.

### ChatGPT (через проект)

1. Создай проект «KPI» в ChatGPT.
2. Загрузи файл `chat-instruction.md` в файлы проекта.
3. Напиши: **«KPI»**.

## Откуда берём данные

| Вариант | Как работает |
|---|---|
| Своими словами | Напиши должность и цели — капсула задаст уточняющие вопросы |
| Файл (.xlsx, .docx, .pdf) | Загрузи текущие KPI, бонусную схему или должностную инструкцию |
| Google Таблица | Коннектор Google Drive в настройках чата, или ссылка с доступом «читатель» |
| Данные по продажам (опционально) | Excel с историей сделок — для реалистичных целевых диапазонов |

## Ограничения

- Целевые значения — гипотезы; проверяй и корректируй по факту первых 1–2 периодов.
- Данные для расчёта нужны в выбранном источнике — без них формулу не применить на практике.
- Веса носят рекомендательный характер; руководитель согласовывает с командой.
- Не заменяет разговор с сотрудником — KPI работают только если согласованы.
- 1С: выгрузи отчёт из 1С в Excel и загрузи файлом в чат.

## Команды

| Команда | Что делает |
|---|---|
| `KPI` | Начать: первый вопрос об источнике данных |
| `Обнови KPI` | Пересобрать таблицу по новым вводным |
| `Добавь показатель` | Добавить показатель (пересчитать веса) |
| `Убери показатель [название]` | Убрать показатель (пересчитать веса) |
